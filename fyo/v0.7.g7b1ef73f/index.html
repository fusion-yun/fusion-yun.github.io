fyo

the fusion-domain ontology

v0.7 — development namespace (IRI version = VERSION base, ADR-guarded)

The fusion/tokamak domain ontology: a hand-curated core (apparatus layer — Machine, CoilSystem, Coil, Plasma, Diagnostic — plus the semantic anchors IDS, Discharge, MachineDescription and FluxCoordinateSystem/COCOS) together with a semantic lift of the IMAS DD 4.1.1 onto spo/BFO — 82 per-IDS schemas plus the deduplicated fyo-common.

Namespace

fyo: https://fusion-yun.github.io/fyo/v0.7.g7b1ef73f/

The trailing slash is part of the prefix: a CURIE expands by concatenation, so fyo:Example resolves to https://fusion-yun.github.io/fyo/v0.7.g7b1ef73f/Example.

Using it

Reference the vocabulary from a JSON-LD document:

{
  "@context": { "fyo": "https://fusion-yun.github.io/fyo/v0.7.g7b1ef73f/" },
  "@type": "fyo:Example"
}

Or load the remote context directly:

{ "@context": "https://fusion-yun.github.io/fyo/v0.7.g7b1ef73f/context.jsonld" }
