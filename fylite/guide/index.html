本篇讲怎么用与结果怎么读。fylite 是什么、本书分几部分，见封面。

三种发布形态，装哪一种取决于你手边有什么

三者装的是同一份页面与同一版内核制品，命令行也由同一个定义文件建出—— 所以三条路上同名的命令是同一条命令（见安装与环境的分发面一节）。

★两条路径调用的是同一个内核：同一份 c_api 导出面，原生库与 WebAssembly 模块出自同一次编译配置。所以浏览器里得到的数与脚本里得到的数是同一个数——这一点由 自动门在每次改动时校验，不靠承诺。

往下读

  • 先跑起来：快速上手 → 浏览器用法 或 Python 用法。

  • 想知道一个结果该怎么信：结果怎么读、 能力与边界。

  • 要一条能照抄的完整路径：算例语料以及它下面的五族典型算例—— 每章的命令与数字都是在本仓实测的。
