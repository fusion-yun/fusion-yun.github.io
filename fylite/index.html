fylite 在线演示

平衡内核编译为 WebAssembly，在浏览器里直接算
FuYun 首页

fylite 是一个自足的托卡马克平衡求解与重构包（无 sp/fy 依赖）。它的数值内核用 Rust 写成，同一份 C ABI 既产出本地 libfylite_rs.so（Python 经 ctypes 调用）， 也产出 fylite_rs.wasm。本站装载的正是后者：183 KB 的二进制， 不包含任何求解器源码，页面上的每一次求解都发生在您自己的浏览器里， 没有服务端计算、也不上传任何数据。

放电设计 →

给定目标位形（R₀、a、κ、δ）与等离子体参数，用等磁通最小二乘反解 12 路 PF 线圈电流，再做自由边界 Grad–Shafranov 求解校验，逐趟退火直到实现位形贴近目标。

动理学平衡重构 →

由 35 道极向磁通环测量（可选叠加压强约束行）拟合 p′/FF′ 多项式剖面， 在 Ip 等式约束下交替求解平衡。可直接跑 EAST 真实炮数据， 也可跑真值已知的合成孪生，量出动理学约束买到了多少精度。

页面调用的内核入口

两个页面只通过 c_api.rs 暴露的 C ABI（v15）调用二进制，没有别的通道：

fylite_rs_element_response
PF 线圈元件在任意点的 ψ、Br、Bz 响应（组装真空场与设计方程）
fylite_rs_mutual_filaments
丝对互感（组装 35×65×65 的磁通环响应矩阵）
fylite_rs_gs_free_solve
自由边界 Grad–Shafranov 求解（满磁通 Wb 规约，轴为极大）
fylite_rs_gs_inverse_solve
平衡重构：外 Picard 迭代套内层带 Ip 等式约束的线性最小二乘
fylite_rs_alloc / _free / _abi_version
线性内存与版本握手

装置数据的出处

页面上的每一个装置数字都逐字取自 fylite 自带的设备描述，没有从文献重新誊抄：

  • PF 线圈（14 个元件）、真空室（40 个元件）、35 道极向磁通环几何： python/fylite/_data/green2018_wpf_64/dprobe.dat，即生成随包 Green 表的 efund 输入卡。
  • 限制器（48 点）：python/fylite/_data/limiter.json。
  • 参考放电 EAST #137985 @ 4.000 s：examples/scripts/{g,a}137985_loop.04000 及随包运行摘要——PF 通道电流、35 道磁通环读数（已扣除线圈贡献）、 EFIT 自身给出的 p(ψ̄)/q(ψ̄)/边界，后者只作对照，不进入求解。

已知边界（诚实说明）

  • 计算网格固定为随包表的 65×65 盒子（R∈[1.2, 2.8] m，Z∈[±1.4] m）。
  • 正解的剖面参数 β₀ 与 EFIT 的 BETAP0 不是同一个旋钮， 二者只在形级映射意义下对应；重构出的磁通跨度与 EFIT 的差别（真实炮约 2%） 主要来自这一点和真空场构造误差，不是求解器误差。
  • 本页不含涡流演化：真实炮的磁通环读数里含真空室涡流贡献，而重构模型中没有 对应自由度。
  • 自由边界解在非锚定模式下走 legacy 边界判据，位形通常判为限制器边界； X 点约束改变的是真空场结构，不强制求解器改判边界类型。
