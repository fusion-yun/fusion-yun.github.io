FuYun website identity — 2026-11-03

Current mark: three nested D-shaped closed magnetic surfaces representing
an elongated tokamak poloidal (minor) cross-section. The inner triangular
three-node graph represents linked knowledge, data and intelligence for
large-scale magnetic confinement fusion science and engineering.
No cloud outline or letter glyphs. This is a symbolic cross-section, not a
computed equilibrium, an exact field-line trajectory or a scientific result.

The magnetic-surface abstraction references the visual vocabulary of fyMHD
and FyrTokamak; paths are newly drawn for this site. Existing FuYun wordmark,
blue/orange/gray palette and canonical canvas sizes are retained.
Canonical source: docs/assets/brand/{mark.svg,brand.json,make_marks.py}.
Regenerate: python docs/assets/brand/make_marks.py --png
Build-only dependencies: fonttools, cairosvg; Liberation Sans font files.
Existing figures/fuyun_mark.svg and figures/fuyun_logo.svg are compatibility
copies, regenerated by the same command and recorded in derived-assets.json.
Do not edit compatibility copies independently.
